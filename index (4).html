FEATURED PROJECT SHORTLISTED — CODE4NATURE 2026

JalSetu

CATEGORY: WATER SECURITY • PREDICTIVE INTELLIGENCE • IoT
TEAM: NOVASTACKS

"An end-to-end predictive water intelligence platform for ward-level groundwater security."

JalSetu tackles India's groundwater crisis with real-time ward-level IoT monitoring, LSTM-based 30/60/90-day depletion forecasting, and automated risk classification — closing the loop with ranked, physically-actionable interventions (recharge, redistribution, crop advisories) and Atmospheric Water Generation (AWG) as a last-resort emergency response.

// CORE PHILOSOPHY
"Shift municipal water governance from reactive crisis management to proactive intervention."

Beyond passive monitoring or dashboards — JalSetu is a closed-loop system: it senses, predicts, classifies risk, recommends the right intervention, and verifies real-world results to continuously retrain itself.

// SYSTEM ARCHITECTURE & DATA FLOW
SENSE Ward-Level IoT Nodes • Every 15 Min
STORE GSM / LoRa → Time-Series DB
PREDICT LSTM: 30/60/90-Day Forecasts
CLASSIFY Risk Score → Safe / Watch / Critical
INTERVENE Recharge • Redistribution • AWG (Last Resort)
VERIFY & IMPROVE Track Recovery → Retrain Models
SENSE → STORE → PREDICT → CLASSIFY → INTERVENE → VERIFY → IMPROVE

// WARD-LEVEL SENSING NODE (ESP32)

• Ultrasonic Groundwater Depth Sensor
• Capacitive Soil Moisture Sensor
• Tipping-Bucket Rain Gauge
• DHT22 Temperature / Humidity Sensor
• GSM/SIM800L (Urban) or LoRa/SX1276 (Rural Mesh)
• Solar Panel + Lithium Battery (Off-Grid)
• AWG Unit — Carbon Filter + UV + Mineralizer (Last Resort)
• Time-Series DB: InfluxDB / TimescaleDB
PROOF-OF-CONCEPT PROTOTYPE FUNCTIONAL

Working prototype covering core sensing, data transmission, LSTM forecasting, risk classification, automated WhatsApp/SMS alerts, a live dashboard, and a Peltier-based AWG demonstration unit.

ML Stack: LSTM (forecasting) + Random Forest (0–100 risk scoring) + decision-tree intervention engine.
AWG Demo Cost: ~₹800 – ₹1,500 (Peltier benchtop unit)
Note: Peltier unit is a benchtop demonstration only — full AWG deployment uses compressor-based dehumidifier hardware.
