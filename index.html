JalSetu

CATEGORY: WATER SECURITY • AWG • DATA INTELLIGENCE
TEAM: NOVASTACKS

"Turning atmospheric moisture into a data-driven water security strategy."

JalSetu combines Atmospheric Water Generation (AWG) with localized environmental and groundwater intelligence to identify water-stressed regions, assess atmospheric suitability, and recommend where and how AWG capacity should be deployed.

// CORE PHILOSOPHY
"We don't build just the machine. We build the intelligence that tells it where to go."

Established AWG manufacturers exist. JalSetu serves as the intelligence, prediction, and optimization deployment layer for atmospheric water harvesting ecosystems.

// SYSTEM ARCHITECTURE & DATA FLOW
ATMOSPHERIC AIR Ambient Moisture Intake
LOCAL DATA ENGINE Groundwater • Humidity • Temp • Water Stress
PREDICTION & RANKING Optimal Location & Capacity Sizing
DEPLOYMENT & IoT Automated AWG Hardware & Sensors
FEEDBACK LOOP Field Telemetry → Refined ML Models
SENSE → STORE → PREDICT → ACT

// PHYSICAL DELIVERY COMPONENTS

• Condensation Chamber
• Storage Tank + Level Sensor
• Carbon Filter & UV Sterilization
• Mineralization Module
• Microcontroller (Telemetry)

PROOF-OF-CONCEPT PROTOTYPE DEMO ONLY

Built a functional benchtop demonstration unit to validate condensation physics and microcontroller telemetry automation based on real-time humidity and temperature.

Stack: Peltier module, Heat sink, Fan, Metal condensing plate, Collection tray, 12V power supply.
Prototype Cost: ~₹800 – ₹1,500
Note: Clear benchtop demonstration model only — distinct from industrial scaled production units.
